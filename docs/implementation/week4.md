- Với giao dịch, bắt buộc kiểm retry cùng key/payload, thay payload 409, timeout sau side effect, hai request đồng thời, rollback, worker crash/restart, scope hai Store và sibling Order. Dùng DB test/schema tạm; không reset tài khoản/quyền/kho demo bằng integration suite.
- Trước merge: contract/docs/codegen, build và tests phù hợp đều đạt; không sửa migration cũ, không commit `.env`/secret, không đưa mẫu tin nhắn nhóm vào repo. Hướng dẫn [verification](verification-plan.md), [capacity](performance-and-capacity.md), [recovery](observability-and-recovery.md) và [FR/NFR](../requirements-acceptance.md) vẫn là chuẩn nghiệm thu.

Domain demo chạy qua máy local/Cloudflare Tunnel: máy, Docker và mạng cần hoạt động. Dùng origin HTTPS đã cấu hình; không nới CSRF/Secure cookie để chạy thử localhost. Bản merge chưa được coi là đã deploy cho tới khi ghi image/commit đang chạy và kiểm lại luồng.
